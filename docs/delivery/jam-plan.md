AI may draft bounded functions/assets only if permitted, and a named person reviews each result. None of this assigns unpaid full-time commitments by default.

## Cut ladder

1. Remove visual effects, extra props, additional dialogue and optional audio layers.
2. Replace enemy behavior with a static readable hazard.
3. Reduce rooms to two while keeping a meaningful return through one gate.
4. Replace complex ability with one context interaction that opens a shortcut.
5. Ship a one-room beginning–action–ending vignette with restart.

Never cut the win condition, reset, input clarity, collision sanity, playable export or credits. A complete tiny game beats a traversal demo with no ending. Keep the flowing terrain and chosen visual reveal recognizable while shrinking the route. The six-stage world route and optional playground are expansion material, not six jam deliverables.

## AI working protocol

Give a tool the accepted mechanic, file boundaries, engine version and explicit done criteria. Request one small change; inspect the diff, run checks and play it before asking for the next. No simultaneous controller rewrites. Track generated asset provenance and organizer declarations. Keep secrets, raw personal chats and private unrelated repositories out of prompts and builds. A failed check is a reason to debug or cut, not to generate a larger replacement blindly.

## Final checklist

Fresh build opens from agreed host and from a backup; assets load without local absolute paths; keyboard focus and mute work; no stuck keys after blur; ability gate works before/after pickup; death and two full restarts work; ending is visible; credits/license/AI declarations complete; no reference screenshots in export; ZIP and demo recording saved; submission received before organizer deadline. Record build commit and URL in the release issue; maintainer authorizes publication.
