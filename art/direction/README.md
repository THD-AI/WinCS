# Visual direction

One style for the whole game, set before any sprite is drawn. The **style master** is our real Rusty Creek stage plus the approved hero, finished as an in-game screenshot; every other image takes it as its first input, then its location collage, the hero sheet and one reference game. The rules distilled from the pack are in [06 – Visual direction](../../docs/06-VISUAL-DIRECTION.md). Click an image for its page: brief, inputs and review notes, with Previous / Next.
