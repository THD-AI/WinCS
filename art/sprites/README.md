# Sprite boards

Sprite reference boards: the hero sheet (approved) and the animation, enemy, item and boss boards that follow the [visual direction](../direction/README.md). Each board is drawn from real photos of the pose or object, keyed on magenta and crushed to a transparent 1x image. Frame lists and status are in [07 – Asset manifest](../../docs/07-ASSET-MANIFEST.md); the pipeline is in [09](../../docs/09-ART-PIPELINE.md). The [poncho photo board](source-boards/ponchos.png) is the source for the hero's poncho.
