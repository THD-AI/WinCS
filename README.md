# WinCS

Private planning workspace for **Vatsal's DegDev 3 game-jam project**, supported by Alexander and Lex. WinCS is the repository label, **Septim Goblin** is the reported registration/team name, and the game title remains undecided.

We are researching and proposing a small, funny-but-deep 2D side-scrolling game. Hollow Knight is Vatsal's main reference; pixel art is his stated preference. No genre, engine, story, final art direction or implementation has been approved yet.

**Important schedule correction:** the event is 23–24 October 2026. The advertised “24h” includes the wider event; the detailed agenda leaves 20 elapsed hours between sprint start and jury start, with 18 scheduled sprint hours. Meals, breaks and rest reduce individual working time further. See the event evidence before planning scope.

This is independent of Voyager. Voyager's floating couch and minigames explain Alexander's interest, but impose no design or integration requirement here. Flipper Zero is an optional later reimplementation question, not a jam target.

Reference screenshots remain third-party research material. Nothing in this repository grants a license to put them, commercial characters, music or extracted sprites into a game. Runtime assets will need a separate provenance manifest.

Check documents locally with `python scripts/check_docs.py`. There is deliberately no playable implementation or dependency installation yet.
