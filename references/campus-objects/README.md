**Eight cleaned collages from 67 new photos.** These expand the existing eight location/item boards without replacing them. Browse each board with Previous / Library / Next; the HTML review also opens all 13 readable transcripts.

Only the finished collages are committed as images. Source photos, working contact sheets and audio remain outside Git. People are removed/replaced with neutral mannequins; brands and incidental signage are abstracted. Inferred views, scale inserts and pose cleanup are listed per board. None is a sprite sheet, measured asset, animation or accepted final game design.
