# Rights and provenance

[← Previous](CONTRIBUTING.md) · [🏠 Home](README.md) · [🖼️ Visual library](references/README.md) · [Next →](README.md)

This private repository contains original planning text and third-party reference media. No public open-source license has yet been selected for the eventual game. Team ownership, contributor credit and publication terms must be agreed before a public release.

Downloaded commercial game screenshots, GIFs and promotional cards remain copyright of their respective developers/publishers. Source pages, direct image URLs, credits, collection dates and hashes are recorded alongside them. They support private design analysis only. Their presence does not grant permission to reuse them as sprites, textures, music, dialogue, characters or marketing for our game.

No development project, commercial sprite sheet, game binary or source code was extracted. A future build must exclude references/ and use original or independently licensed runtime assets with a separate manifest. Review redistribution permission before making the reference library public; replacing images with source links may be appropriate.

The supplied personal chat screenshot and raw transcript are not included. The team brief is a minimal planning digest. Voyager remains a separate project and contributes no runtime assets or source code here.
